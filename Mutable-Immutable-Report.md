1. What does mutable mean?
Mutable means the data can be changed.

2. What does immutable mean?
Immutable means the data cannot be changed

3. What allows MutableStudent objects to change?
The setter methods.

4. Why does ImmutableStudent not have setter methods?
The fields are set to final, so they cannot be changed with setter methods.

5. What is the purpose of final on the fields in ImmutableStudent?
Each field can only be assigned data once.

6. What is the main difference you observed when testing the two classes?
MutableStudent can be updated using setter methods and ImmutableStudent cant be updated.
